# Secure File Encryption and Decryption System

## Project Overview

The Secure File Encryption and Decryption System is a Python-based desktop application developed using Tkinter. It allows users to encrypt files and decrypt them using a password.

The project demonstrates basic file security concepts and the use of cryptographic libraries in Python.

## Features

- Simple graphical user interface using Tkinter
- File selection through a file browser
- File encryption and decryption
- Password-based key derivation
- Support for different file types, subject to application testing

## Technologies Used

- Python
- Tkinter
- Cryptography (Fernet)
- Visual Studio Code

## Requirements

- Python 3.11
- cryptography

## Installation and Setup

1. Clone or download this repository.
2. Install the required library:

   ```bash
   python -m pip install cryptography
   ```

3. Run the application:

   ```bash
   python main.py
   ```

Use the Python interpreter configured for your environment if the `python` command points to a different version.

## How to Use

1. Launch the application.
2. Select a file using the Browse option.
3. Enter the required password.
4. Choose the encryption or decryption operation.
5. Check the output file or output folder.

## Learning Outcomes

This project provided practical experience with Python programming, GUI development, file handling, and cryptography concepts.

## Disclaimer

This is an educational project. Review the key derivation and password handling implementation before using it to protect important or sensitive data.
